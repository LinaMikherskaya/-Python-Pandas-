# -Python-Pandas-
Скрипт на Python, демонстрирующий процесс очистки (data cleaning) и трансформации данных предоставляющих информацию по школам и преподаваемым предметам. Цель проекта — подготовить сырые данные для дальнейшего анализа распределения ключевых дисциплин (английский, математика, физика, химия) по различным штатам.
