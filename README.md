# -Python-Pandas-
Скрипт на Python, демонстрирующий процесс очистки (data cleaning) и трансформации данных предоставляющих информацию по школам и преподаваемым предметам. Цель проекта — подготовить сырые данные для дальнейшего анализа распределения ключевых дисциплин (английский, математика, физика, химия) по различным штатам.

Выполненные задачи (Steps):
Загрузка данных: Импорт данных из формата .xlsx в DataFrame 
Фильтрация: Удаление из выборки школ, которые предлагают менее 3 учебных предметов
Очистка данных (Data Cleaning): Применение регулярных выражений re.sub("[!@()#\s_]", '', str(x)) для очистки данных столбца state_code (удаление спецсимволов и приведение к единому буквенно-цифровому формату)
Трансформация (Feature Engineering): Поиск строковых вхождений названий предметов (english, maths, physics, chemistry) и преобразование их в бинарные признаки (1/0)
Агрегация: Группировка данных по state_code с подсчетом количества школ, предлагающих целевые дисциплины в каждом штате
Визуализирование: Построение столбчатой диаграммы, предоставляющей информацию по популярности целевой дисциплины в каждом конкретном штате
